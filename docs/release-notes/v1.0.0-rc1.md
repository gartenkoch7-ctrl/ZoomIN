**Release-Kandidat 1 für ZoomIN 1.0** – kostenlose Open-Source-Bildschirmlupe für Windows.
*English summary below.*

## Neu
- Vollbild, Lupe und angedockter Bereich (1×–16×, stufenlos, weich animiert)
- Unsichtbar bei Bildschirmfreigabe und Aufnahmen
- Farbfilter (7), Kontrast/Helligkeit, text-optimierte Glättung
- Vergrößerter Mauszeiger mit Kontrastrand, Suchhilfe
- Folgt Tastaturfokus und Textcursor, Fokusrahmen
- Mehrere Monitore mit eigener Zoomstufe je Monitor
- Einstellungsfenster, Tray-Symbol, Profile, Autostart, Erststart-Assistent, Deutsch/Englisch
- Wächterprozess: Neustart und Aufräumen nach Absturz

## Getestet / ungetestet
Es gab keine Beta-Phase. Getestet wurde auf **einem** Rechner – bitte melden Sie Erfahrungen mit
anderer Hardware über die Issue-Vorlage „Hardware-Bericht“.

| Bereich | Status |
|---|---|
| Windows 11 23H2, NVIDIA RTX 3060 Ti, 1 Monitor 1080p 60 Hz | ✅ getestet |
| Zoom an/aus < 25 ms, 60 fps, 0 % CPU im Leerlauf | ✅ gemessen |
| Unsichtbar in Screenshots (GDI-Aufnahme) | ✅ automatisch geprüft |
| Unsichtbar in Teams / Zoom / Discord / Browser-Freigabe | ⚠️ noch nicht geprüft |
| Grafiktreiber-Neustart, Auflösungswechsel | ✅ automatisch geprüft |
| Absturz → Neustart, AppBar und Zeiger aufgeräumt | ✅ automatisch geprüft |
| Fokus/Textcursor in Win32-/WinForms-Fenstern | ✅ geprüft |
| Fokus/Textcursor in Edge, Office, VS Code, Terminal | ⚠️ ungetestet |
| 144 Hz, Win+L, Ruhezustand | ⚠️ ungetestet |
| Mehrere Monitore, gemischte DPI | ⚠️ ungetestet (kein zweiter Monitor) |
| Laptops mit Hybrid-Grafik, Windows 10 | ⚠️ ungetestet |
| HDR | ⚠️ bekannte Einschränkung – Farben können abweichen |
| ARM64 | ❌ nicht unterstützt |

## Bekannte Einschränkungen
- Nicht digital signiert: SmartScreen-Warnung beim ersten Start.
- Animierte Zeiger (Sanduhr) werden nur mit dem ersten Bild vergrößert.
- Im angedockten Streifen kann man nicht klicken.
- Geräte, die das Bildsignal direkt abgreifen (Capture-Karte, Beamer), zeigen den Zoom.

**English:** First release candidate of ZoomIN 1.0, a free open-source screen magnifier for
Windows 10 (2004+) and 11, x64. Tested on one Windows 11 PC with one monitor; multi-monitor,
hybrid graphics, Windows 10, 144 Hz and screen-sharing apps are untested – please report your
results with the "Hardware report" issue template.
